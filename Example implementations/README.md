This folder contains examples of implementations of Epic Kanban System workflows, that is
documents explaining how Epics can flow between different Epic states within a given Epic Kanban System
implementation.

* **ISIS Mantid Epic flow guidelines.docx**: Document used to explain and specify how
Epics can flow between states for the Epic Kanban System used at ISIS Neutron and Muon Source with
the Mantid software. This word document was copied over Jul 24th 2025 from an internal to ISIS document area.
